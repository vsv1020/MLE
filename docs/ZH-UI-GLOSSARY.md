# 中文界面术语表

麻薯背单词面向中国用户，用来学英语、法语、泰语。界面只有简体中文：文字直接写在代码里，不做多语言切换。
所有界面文字（包括无障碍标签 accessibilityLabel、通知、小组件、灵动岛、快捷指令、分享卡片、家长报告 PDF、错误提示）都用中文。

## 不翻译

- 学习内容本身：外语单词、音标、例句原文、词性标签以外的词条字段
- `accessibilityIdentifier`、产品 ID、UserDefaults 键、通知标识、日志、代码注释
- 品牌名里的 “Plus”

## 风格

- 简短、温暖、口语化，孩子和家长都看得懂。不用“您”，用“你”。
- 中文标点：，。！？：；“”（）。省略号用 “…”。
- 中文和数字、拉丁字母之间加一个空格：`连续 12 天`、`麻薯 Plus`、`A1–A2`。
- 没有单复数：`"\(n) cards"` → `"\(n) 张卡片"`，不要写 `(s)`。
- 不加 emoji，除非原文已经有。
